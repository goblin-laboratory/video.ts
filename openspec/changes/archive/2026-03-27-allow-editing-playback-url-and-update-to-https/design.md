## Context

当前 App.tsx 中使用了只读的 Input 组件显示播放地址。需要：
1. 移除 `readOnly` 属性使输入框可编辑
2. 添加状态管理来跟踪用户自定义的 URL
3. 更新默认 URL 为 HTTPS 协议

## Goals / Non-Goals

**Goals:**
- 支持用户编辑播放地址
- 更新默认地址为 HTTPS
- 保持现有分段选择功能不变

**Non-Goals:**
- 不添加 URL 验证功能
- 不修改播放器核心组件
- 不添加 URL 历史记录功能

## Decisions

### Decision 1: 使用本地状态管理自定义 URL
- **选择**: 为每个选项添加独立的 URL 状态
- **原因**: 简单直接，不需要复杂的状态管理
- **替代方案**: 使用 `useMergeValue` 来管理默认值和自定义值

### Decision 2: 实时更新 URL
- **选择**: 输入框内容变化时立即更新播放器源
- **原因**: 提供即时反馈，无需额外确认按钮
- **替代方案**: 添加确认按钮，用户点击后才更新

## Risks / Trade-offs

| Risk | Mitigation |
|------|------------|
| 用户输入无效 URL 导致播放器错误 | 这是预期行为，由播放器内核处理错误 |
| 用户修改 URL 后切换选项丢失自定义 URL | 设计上每个选项独立，切换时重置为该选项默认值 |
